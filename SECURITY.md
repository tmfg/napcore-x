## Security Policy

### Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report vulnerabilities privately to:

nap@fintraffic.fi

Include:

Description of the issue
Steps to reproduce
Affected versions
Potential impact
We will acknowledge receipt within 5 business days and work with the reporter to validate and remediate the issue.

### Supported Versions

Version Supported
main ✅
